## 📝 Descrição do Projeto
Este projeto foi desenvolvido como parte do desafio da **Santander Dev Week 2025** na plataforma da **DIO**. O objetivo é demonstrar o ciclo **ETL (Extract, Transform, Load)** utilizando Python para transformar dados brutos em mensagens de marketing personalizadas.

---

## ⚙️ O Fluxo de Dados (ETL)

### 1. **Extract (Extração)**
Os dados foram extraídos de uma lista interna no Python, simulando o recebimento de registros de clientes (ID, Nome e Conta).

### 2. **Transform (Transformação)**
Implementação de uma função que gera mensagens de marketing dinâmicas. O script percorre a lista de usuários e cria um conteúdo personalizado para cada um, focando em engajamento e novos investimentos.

### 3. **Load (Carregamento)**
Os dados transformados são exibidos no console (output), simulando o envio dessas informações para um banco de dados ou sistema de notificações.
